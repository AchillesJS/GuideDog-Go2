# Contributing

GuideDog-Go2 is in early bootstrap. The maintainers are currently coordinating a two-person development workflow; external contributions may be paused until interfaces and licensing are agreed.

Before proposing a change, open an issue describing the problem, expected behavior, and a minimal test. Use a feature branch and a pull request rather than pushing directly to `main`.

For bug reports, include your platform, ROS 2 and Gazebo versions, robot simulator commit, exact commands, observed logs, and reproduction steps. Do not upload secrets or proprietary data.

**Safety:** do not describe unverified simulation functions as safe for real-world mobility assistance.

**Licensing:** the maintainers have not selected a license for original project code yet. Contact them before sending copyrightable code contributions.
